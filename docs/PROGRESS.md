## Environment notes
- Machine has JDK 17 on PATH and JDK 22 at `C:\Program Files\Java\jdk-22`. Build with `JAVA_HOME` pointing at JDK 22 (compiles with `--release 21`) or install JDK 21. The Maven enforcer rejects JDK < 21.
- Docker Desktop must be running for docker-compose and Testcontainers.
- `git config core.hooksPath .githooks` must be set once per clone (enables the attribution-stripping hook).
- A native Windows `redis-server` listens on 127.0.0.1:6379 (no password). Docker Redis is therefore on **6380** locally (`REDIS_PORT` in the env file). Change ports with `bash infra/scripts/init-local-env.sh set <NAME>_PORT <port>`.
- Host JVM default zone is `Asia/Calcutta`, which Postgres 17 rejects; every service `main()` and the test JVMs force UTC.
- In Git Bash, prefix `docker exec` commands with `MSYS_NO_PATHCONV=1` (otherwise container paths get rewritten).

- 2026-11-07 — **Persistence is Spring JdbcClient + explicit SQL, not JPA**, in every service. Reasons: tstzrange and PostGIS columns, exclusion constraints and the conditional `UPDATE ... WHERE status = ? AND version = ?` transitions the contracts require are simpler and more visible in SQL; the pure domain model maps by hand. Flyway owns the schema. `services/identity` is the reference implementation (layout, outbox, tests).
- 2026-11-07 — Outbox relay per service: scheduled poll with `FOR UPDATE SKIP LOCKED`, stops at first send failure (keeps per-key order), deletes private-topic rows after publish, purges published rows after 7 days.
- 2026-11-07 — Identity hardening (security review): 60s resend cooldown + 5 codes/hour per account and purpose (advisory lock); forgot-password throttles silently; atomic failed-login counter; locked accounts get the same 401 as a bad password; refresh family absolute lifetime 90 days; dev code logger only under local/test; aws profile requires `sslmode=verify-full` and Kafka TLS.
- 2026-11-07 — Gateway is reactive and does not use the servlet-based shared modules; it duplicates the ~20-line JWT validator (RS256, issuer, audience, UUID subject). Services re-validate tokens (defence in depth). `/internal/**` is denied at the edge (401 anonymous, 404 authenticated).
- 2026-11-07 — Accepted risks (revisit in phase 11): (1) `POST /auth/register` returns 409 for a taken email (account enumeration, mitigated by the 5/hour/IP limit); (2) Spring Cloud Gateway's Redis rate limiter **fails open** if Redis is down — Identity's own lockout and code throttles still apply, and gateway health reports DOWN; (3) gateway 429 responses have no problem+json body yet; (4) base images not pinned by digest.
